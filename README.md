# 单品展示 TVC｜Seedance 2.5

将单张产品图、同一产品的少量多角度图或明确成套附件，整理为一版可复制到 Seedance 2.5 的完整产品展示广告文字提示词。

默认输出 30 秒、16:9、无旁白的展示型 TVC。产品始终是画面主体，重点展示材质、可见结构、操作反馈、使用结果与结尾品牌定格；用户指定的时长、画幅、调性和文案优先。

## 使用方式

将本仓库安装到支持 `SKILL.md` 的技能环境中，提供产品参考图，并调用：

```text
使用 $product-showcase-tvc-seedance-prompt，将我的产品参考图编译为一版完整的 30 秒 Seedance 2.5 单品展示 TVC 提示词。
```

可同时说明画幅、广告调性、已确认的卖点、正式广告语和声音要求。

## 输出内容

- 广告基础设定与产品视觉锁定。
- 一个产品主概念及整体摄影风格。
- 默认 6–9 个镜头、连续覆盖 0–30 秒的时间线。
- 声音设计、画面短文案、一致性与生成限制。

产品特征以参考图和用户确认的信息为准，不虚构不可见结构、模糊品牌文字或未经证实的参数。

## 适用范围

适合单品展示、材质特写、结构细节、必要的局部手部操作和可见卖点证明。多张参考图应属于同一产品或明确成套附件。

本技能输出文字提示词，不直接提交视频生成任务。人物叙事、对白喜剧、品牌活动故事和高概念动作广告应使用单独安装的 `creative-tvc-seedance-prompt`；使用小云雀直接生成视频应使用单独安装的 `xyq-skill`。这两个技能未包含在本仓库中，单品展示提示词编写无需依赖它们。
